# 《二哈有福》故事包

这是《二哈有福》的内容源文件。它是游戏项目的一部分，不依赖 MongoDB 中的草稿数据；数据库中的故事记录应由这些文件按需导入，并在发布时生成不可变版本。

## 文件

- `design.md`：世界观、角色、关系、魔法与声音演出约定。
- `plan.md`：共同线、角色线和真结局的章节与实施计划。
- `replay-design.md`：多周目规则、路线差异、真结局条件、声音重玩与待实现验收。
- `chapter-01.ink`：第一章的 Ink 原始剧本，可直接复制到工作台编译。
- `assets/README.md`：未来配音、声纹参考、音乐和音效的资源约定。

## 当前范围

仓库中保存的是已修订的第一章《下跪咒与新生注册》源稿；此前数据库已发布的 v1 仍是修订前版本，修订稿尚未重新导入或发布为 v2。2026-10-25 增补的多周目方案仍是文档设计。后续章节只有设计和验收目标，没有提前写入剧情正文。第一章使用文字和标签验证剧情；`voiceId`、`audio` 和 `music` 仍然是素材关联的元数据，不代表已经有真实音频。

## 导入约定

导入工作台时，将 `chapter-01.ink` 作为当前故事的 `source`，再按 `design.md` 中的角色表填写角色配置。发布前要在工作台编译并保存；后续章节完成后再合并为完整主剧本或按产品需要拆分导入。

## 多周目设计入口

建议先读 [多周目设计](replay-design.md) 了解三条女主路线与福门回响，再读 [章节计划](plan.md) 了解后续工作。当前“新开一局”不继承通关记录；第一章结束不算一周目通关。本次设计调整未启动服务。
