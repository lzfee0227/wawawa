# 《二哈有福》剧情展开计划

目标是先做一个约 20～30 分钟的短篇语音互动故事，再根据实际试用决定是否扩展。每一环都先完成设计、Ink 原稿、编译验证和关键路线检查，再开始下一环。

## 章节总览

| 章 | 标题 | 核心地点 | 主要任务 | 关系/状态重点 |
|---|---|---|---|---|
| 01 | 下跪咒与新生注册 | 新生礼堂、钟楼回廊、旧档案室门口 | 系统激活，认识主角团，拿到福门线索 | 初始名声、四人信任、马二福第一印象 |
| 02 | 缺页的校史 | 图书馆禁阅层、校史塔 | 查明李家与福门的关系 | 调查进度、是否向马二福坦白 |
| 03 | 新生试炼与借福术 | 试炼场、潮汐温室 | 选择公开竞争或暗中调查 | 第一次使用/拒绝借福，路线锁定前的关系分歧 |
| 04 | 地下旧礼堂 | 福门外环、废弃礼堂 | 四人进入地下，见到被抽走好运的证据 | 顾长明现身，系统因果债开始有实际后果 |
| 05 | 马家来信 | 马家旧宅、校董会会客厅 | 了解马二福的家族约束 | 马二福路线核心；是否把福印交给她 |
| 06 | 福门之夜前夕 | 霍海校园、钟楼顶 | 校董会准备抽取新生好运 | 伙伴是否互相信任，决定最终支援人数 |
| 07 | 福门之夜 | 福门核心、潮汐火山心室 | 选择关闭、摧毁、接管或转交福门 | 终局选择、因果债、调查与关系条件 |
| 08 | 留给谁的福 | 新校舍/离校车站 | 展示结局后的生活 | 马二福 True End、两条 Good End、Normal/Bad End |

## 场景与场地清单

- **新生礼堂**：开场冲突、公开身份和家族差异第一次被听见。
- **钟楼回廊**：适合短对话、秘密交换和系统提示；钟声可以作为音频锚点。
- **旧档案室门口**：第一章结尾留下悬念，不在第一章解释完整真相。
- **图书馆禁阅层**：何敏的调查主场，强调证据与规则。
- **潮汐温室**：罗金妮的植物魔法和疗愈场景，承载轻松关系段落。
- **试炼场**：公开声望、竞争和借福术的风险展示。
- **地下旧礼堂/福门核心**：主线冒险和终局场景。
- **马家旧宅**：马二福的家庭压力、守福印和真结局条件。

## 重要剧情选择设计

1. **开场如何回应马二福**：沉默、路过、反击、道歉。改变名声与马二福初始信任，但不跳过主线。
2. **是否接受罗金恩的解围**：决定兄弟信任和后续校园消息来源。
3. **是否把档案线索交给何敏**：决定调查速度与证据路线。
4. **是否救被法阵影响的学生**：牺牲时间/系统积分换取承福标记，建立道德主线。
5. **是否向马二福坦白她的家族与福门有关**：决定 True End 是否可达。
6. **公开参加新生试炼还是暗中调查**：决定声望路线或证据路线。
7. **是否使用借福术**：短期变强，长期增加因果债。
8. **福门最终如何处理**：关闭、摧毁、接管或把守福权交还给马二福。

## 结局条件草案

- **True End《这一福，留给你》**：`trust_ma_er_fu` 高、`knows_bloodline` 为真、因果债可控，最终选择把守福权交给马二福并共同重订规则。
- **Good End《答案之外》**：何敏信任与调查进度高，摧毁福门，公开证据。
- **Good End《从小到大的约定》**：罗金妮信任高，选择保护普通学生并离开家族控制。
- **Normal End《霍海的新校规》**：伙伴关系稳定但没有完成任一恋爱路线，四人推动有限改革。
- **Power End《最年轻的校董》**：接管福门，成为新的权力中心。
- **Bad End《宿主权限变更》**：因果债过高，系统接管主角的选择。
- **Bad End《下跪的人》**：长期逃避关键选择，主角成为福门的代价。

## 每章交付模板

每一章完成时应同时提供：

1. 可阅读的章节梗概与选择表。
2. 可直接编译的 `.ink` 原稿。
3. 新增变量、标签和角色引用说明。
4. 至少一条主路线和一条替代路线的编译/运行检查。
5. 对声音素材的预留清单；没有真实音频时明确标记为待制作。
