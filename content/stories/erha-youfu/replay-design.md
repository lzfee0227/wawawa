# 《二哈有福》多周目与角色路线设计

设计版本：0.5；2026-10-25。状态：设计方案；第一章连续性与首章选择反馈修复已写入原始 Ink，尚未重新导入数据库。需求前缀 `EY-RP` 仅用于本故事设计追踪，不表示平台已有这些功能。

## 核心体验

第一次游玩是“寒微新生靠伙伴和系统闯出一条路”；第二次是“同一件事，从另一个人的处境听出不同答案”；第三次或后续游玩才可能是“理解好运的来源，与马二福把福门的规则改写”。周目数不代表等级，也不直接开启真结局。

三位女主首轮均可进入，罗金恩始终是独立的兄弟与行动伙伴。每条恋爱线都包含冒险、冲突、相互选择、事业落点和婚后尾声。马二福有首轮可达的 Good End，也有解开世界核心谜题后的 True End。玩家不必为了真结局先与另两位女主恋爱，更不必故意打出悲剧。

推荐体验顺序是金妮线（理解人）→何敏线（理解规则）→马二福真线（共同改写规则），这是推荐而非强制。马二福是隐藏主轴，但不是把其他女主降格为假路线；也允许马二福 Good End→伙伴调查线→马二福 True End。每条路线都必须有自身不可替代的真相、行动和幸福尾声。

## 周目究竟意味着什么

采用“平行可能性 + 福门回响”，而非男主每次结婚后抛下伴侣倒转时间。每一轮的结局在所属故事线中成立；开启新一轮不会在叙事中杀死、抹掉或否定上一轮的人。

- 玩家记得自己听过的故事；新一轮的李二哈不知道上一轮的完整人生。
- 系统能从福门取得少量无姓名、无亲密细节的因果回响，必须先播报，主角才有理由提出新的问题。
- 女主不会自动继承另一轮的恋爱记忆。马二福偶尔听见“漏掉的半拍”，不代表她知道或默认接受另一轮的关系。
- 回响提供调查方向，不提供无需证明的答案。新一轮仍须找到当前世界的证据、取得同伴信任。
- 启动新周目由玩家主动选择。Bad End 后可回到关键选择，也可开新周目；不会自动循环或惩罚读档。

故事内的系统继续是优秀辅助者：提供可核实情报、护助和代价提醒。反派可利用旧版权限协议，但普通系统帮助不应被结尾全盘翻成骗局。只有玩家在明确警告后连续接受危险托管，才可能走到“宿主权限变更”。

## 每次重玩具体增加什么

| 阶段 | 玩家体验 | 新内容 | 不强制的事项 |
|---|---|---|---|
| 初次完整游玩 | 学校冒险、首次逆袭、选择伴侣或伙伴路线 | 一条完整路线；可获得两类回响之一；首轮马二福 Good End 可达 | 不要求先失败；不锁马二福恋爱线 |
| 已完成一条路线后的游玩 | 调查另一种解决办法，重新理解配角 | 根据已获回响出现少量新问法和解释；另一条路线有独有场景与行动 | 不依靠通关次数自动开真线；重复同一路线不刷数值 |
| 回响齐备后的游玩 | 准备马二福真线，在当前世界重建证据与信任 | 旧契约中的共同签署条款、真线第 6～8 章 | 不要求收集全部结局，也不要求另两条恋爱结局 |
| 真结局之后 | 重听关系故事、补其他路线、回顾伏笔 | 结局与已读段落回顾；仍可正常开新轮 | 不循环叠加“更真”的结局或提高刷取门槛 |

## 三条女主线与伙伴线

### 罗金妮：有人记得你是谁

主题是“面对魂穿后的变化，亲密能否重新建立”。金妮察觉二哈记忆和习惯变了。主角必须认真回应她的疑问，坦白自己的记忆断层与现在的身份处境，不能用童年记忆骗取感情。她选择的是现在与自己共同承担的人。

专属场景：潮汐温室、平民学生诊疗站、暴雨中的旧渡口。她擅长疗愈，也会反对主角用自己的身体替所有人承受反噬；玩家必须接受她能独立救人的方案。结局落点是跨城镇互助网络及其自治节点，负责长期互助、培训和资源分配；主角与金妮共同协调，负责人权限由成员轮换和公开记录约束。必要时，这个网络可以与伙伴线的机动灾害响应队签订协作协议，但两者是不同组织。

关键决定：告知记忆异常→把救援名单交给她统筹→放弃独占功劳、共同建立互助护界。完整揭示后获得“众人可分担代价”的回响。Good End 中两人保住学生、封闭当地抽取装置，建立有自治权的平民魔法互助所；李二哈与金妮共同协调，负责人权限由成员轮换和公开记录约束。尾声明确两人成婚，并保留伙伴往来。

### 何敏：把命运写成能被检验的规则

主题是“知道答案的人，是否愿意让别人检查答案”。何敏会质疑系统建议；主角需要共享真实代价记录并接受复核。她不是替玩家计算最优攻略的工具人。

专属场景：禁阅层、契约实验室、校董公开听证。行动是获取凭证、复现实验、公开证据，和金妮线的救援玩法不同。结局落点是允许当事人质询、复核和申请撤销的契约审议所，公开听证不是一次性演讲，而是长期运行的制度。

关键决定：交出系统代价记录→保留对自己不利的证据→与何敏共同公开契约漏洞。完整揭示后获得“权限可以撤销”的回响。Good End 中摧毁的是抽取组件，保留供普通人使用的安全设施；两人建立独立的契约审议所，李二哈参与议事但接受质询、复核和撤销程序。尾声有相互求婚/成婚的明确承诺。

### 马二福：我的名字不是一张契约

主题是“从名字的占有，到把选择权交给彼此”。保留性转马尔福式的贵族校花、傲娇与最初敌对。她必须为下跪咒负责：承认伤害、正式道歉、承担校纪后果，并在后续付出行动。玩家不必容忍羞辱才能攻略她；坚定要求尊重可以增加信任。她的 True End 是情感主轴和隐藏世界真线，但不否定另外两条路线的幸福价值。

专属场景：钟楼独处、马家契约厅、守福印交接仪式。核心冲突是家族将她的姓名当成继承契约的签名。她可以拒绝家族，也可以拒绝主角替她安排的人生。结局落点是由多方代表参与、可被公开质询的地区议事团，权力受共同规则约束。

首轮 Good End《名字写在一起》：双方在明确自愿下解除她的继承束缚，封住本地福门；凭救援、证据与谈判建立新的地区议事团，马二福与李二哈共同承担议事权，且任何一方都受公开规则约束。两人成婚，“这一福，留给你”先落在两人的生活里。旧制度在别处仍存在，但不是暗示这段婚姻虚假或注定失败。

True End《这一福，留给你》：在同样完整的恋爱基础上，用两类回响指引当轮调查，发现守福权不能靠换一个主人解决。马二福亲自拒绝单人继承，主角也放弃独占承福权；众人建立可撤销、公开的共同契约。李二哈可以担任受规则约束的一方领袖，但领袖权限可被复核、撤销并由多人共同承担。婚礼尾声将标题落成“有福，是她愿意与你一起过日子”，而非把女主当作通关奖品。

### 罗金恩与伙伴结局

罗金恩的独有作用是联络平民学生、搬运证据和组织撤离，能在不同路线提供支持；不能只负责搞笑或替妹妹安排恋爱。隐瞒危险会损害兄弟信任，坦白并兑现承诺可以修复。

第 3 章可主动选择伙伴路线。第 4～5 章选择一个调查方向：救援机制或契约机制，每轮最多获得一类新的回响。由金妮或何敏作为非恋爱同伴参与，足以让只想攻略马二福的玩家补全真相。伙伴结局须由玩家主动选择单身；恋爱推进失败时明确给出修复机会或关系破裂分支，不把承诺过的婚恋尾声悄悄换成单身。无论恋爱还是伙伴路线，组织落点都由多人参与、公开规则和可撤销授权组成，主角负责协调或承担代表职责，不独占全部权力。

## 共同线如何分流

第 1～2 章为共同线。第 3 章试炼后提出“接下来想与谁一起查下去”，先选同行方向，再在关系场景中明确是否追求感情。分流不等于立刻告白成功。

- 不用最高好感度自动分配女主，不允许系统替玩家决定喜欢谁。
- 同行选择前给一段短回顾，提示每个人的关注点。每屏/每轮优先 2～3 项，四人选择可分两轮询问，但不能提前替玩家筛掉路线。
- 第 4～5 章以独有行动和价值冲突形成恋爱，而非只换名字复用对白。
- 第 6 章确认关系与终局方案；第 7 章处理危机；第 8 章兑现事业、婚恋和伙伴去向。
- 路线间可以汇合到同一地点，但信息、任务与说话人不能无条件共享。没有取得的线索不得突然被主角说出。

## 解锁状态与真结局条件

以下是未来实现契约。数值阈值暂定，后续剧本完成后须检查实际可达性。

跨周目记录仅有：`echo_shared_cost`（可分担代价）、`echo_revocable_oath`（可撤销权限）、已达结局 ID、已听内容 ID 和内容版本。回响必须先在正文中完成揭示，再在有效路线结尾结算；单纯进入某条路线、死亡或走到第一章 `END` 均不计通关。

每轮重置：所有信任、声望、勇气、调查值、债务、技能、道具、关系承诺、当前回合；主角不继承另一轮的伴侣。`completed_runs` 即使记录，也不作为解锁门槛。

新轮开始时拍下当时的回响快照。本轮中其他存档取得新回响不会改变当前选项；玩家需再开新轮使用它。没有账号的本地版本未来需明确玩家档案边界，不能把某个玩家的解锁全局发给所有故事或所有玩家。

真线入口条件全部满足才出现：

1. 新轮快照同时拥有两类回响；罗金妮/何敏恋爱线与伙伴调查线都可提供对应回响。
2. 本轮主动选择马二福恋爱线，`trust_ma_er_fu >= 4`，她已道歉并修复开场伤害。
3. 本轮重建共同分担方案与撤销条款证据，`investigation >= 3`；仅听过回响不够。
4. 本轮已坦白血脉与系统代价、双方确认关系，并让马二福自行决定是否签署新契约。
5. 本轮 `causality_debt <= 2`；超出时第 6 章提供有代价的偿还机会，不能一笔首章借势就永久锁死真线。
6. 玩家在第 7 章主动选择“与她共同重订契约”，而非自动进入。

不满足真线条件时，马二福 Good End 仍可达。缺失项用不剧透的提示表达，例如“你还不知道，承受代价是否只有一个人的办法”。不得要求玩家查数值攻略或在终局突然补一个未预告的条件。

Good End 与 True End 的浪漫价值平等；True 表示揭示更完整的世界机制，不表示其他女主是假选项。两类回响各自来自完整路线的解决方案，不是女主用来送给主角攻略别人的道具。

## 纯语音重玩

- 新一轮提供“从头听／听已读摘要后继续”固定选项；第一次出现的剧情和关键选择不能跳过。
- 摘要只总结玩家已听且当前分支适用的内容。不提前透露未到达的路线、人物身份或真结局。
- 跳过对白不能跳过状态执行；重玩仍在合法选择点做选择，不能直接设置好感度。
- 每个新回响先用一句可听懂的提示引出。禁止仅靠画面、颜色或只能在调试面板看见的变量区分新内容。
- 通关回顾只说明本轮关系、结局和解锁的新调查方向。下一轮需玩家确认，不自动开始。
- 语音命令仍映射当前给出的选项。重听、摘要、章节回顾是未来播放/导航能力，不能假装已有。

| 登记台旧校徽 | 选择信任谁 | 围绕缺口多一个可选调查问题；各人物反应体现其职责，不直接解释整个福门 |
| 钟楼第九声 | 地下回声慢半拍 | 两类回响齐备时主角听见另一道回应，系统给出“还有第二个签署位置”的待验证线索 |

第一章本轮修复：李博特与李二哈改为魂穿者与身体身份；四种开场回应各自留下不同的即时台词；登记台可直接把校徽交给马二福，自己保管才进入后续二选一；直接交给马二福与自己保管后再追上她，分别表达“先信任她”与“先保留证据”的差异；交给何敏校徽只增加调查，不设置 `knows_bloodline`；道歉路线有独立的校纪责任台词；校徽归属写入 `badge_holder` 并在章末按持有人收束；删除无效的 `accepted_help`；系统提示改为身份置换；系统结尾改为故事内的下一处残响提示。开场施咒仍是必须承担的伤害事件，马二福后续需要道歉、受校纪后果并用行动修复关系。仓库源稿与数据库旧 v1 的版本差异已在故事包文档中明确。

## 平台能力与内容实施界限

当前已有：独立新会话、固定版本、Ink 条件分支、存档恢复。当前“新开一局”就是全新存档，不继承任何通关记录；第一章结束只是章节演示结束。

可以先用 Ink 内容完成三条不同路线，让玩家手动重开体验。若要自动记住通关、解锁真线、跳过已读内容，则需要后续平台规格与代码：玩家档案、带版本的结局事件、服务端校验解锁、创建会话时注入只读快照、已读内容记录。客户端/模型不能任意注入变量。旧 v1 会话不能换入新 Ink，也不追认第一章演示为通关。
