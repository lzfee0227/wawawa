# 指定章节试跑验收

日期：2026-10-25。规格：[SDD-006 CP01–CP06](../specs/006-chapter-playtest.md)。

## 实现

- 版本内的作者声明决定章节和前情入口，编译校验声明，发布前逐入口检查；HTTP 只接受版本及入口 ID。
- 前情初始化由 Ink 执行，不接受客户端变量改写。普通开局和 MCP 保持原契约。
- 模拟器支持版本、章节、预设选择，独立试跑存档、刷新恢复、固定版本重试及返回正常进度。
- 完整《二哈有福》新增 22 个预设（第二、三章共同线，第四至第八章四路线）。内容回归验证这些预设与合法路径变量及选项一致，并能继续到对应结局。

## 限制

预设是作者定义的合成前情，不恢复以前节点的 Ink 访问次数，不是玩家真实章节检查点。没有跨版本存档迁移、玩家跨会话回响或新的音频能力。已有数据库内容未自动修改；需要导入更新后的完整 `story.ink` 并发布新版本才能选择其中的章节预设。已结束的第一章演示存档仍固定原版。
