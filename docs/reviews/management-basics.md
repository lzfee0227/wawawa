# 管理平台基础迭代验收

日期：2026-10-25。基线为已合并 PR #18，之前的 #6–#11 提供 MCP，#12–#18 提供《二哈有福》完整内容。历史 MVP 报告保持原时点数据，本页记录当前迭代。

## 范围与结果

SDD-004 优先让作者把真实剧本导入、发布并通过选项验证。新增空白模板、独立 Ink 草稿导入、书架更新时间/已读取发布状态、指定发布版本试玩。普通模拟器和角色添加使用支持 HTTP 局域网的请求 ID 生成工具。没有增加外部依赖、改变数据模型或扩展 MCP。

文件读取、校验或创建草稿失败时保留当前编辑内容；未保存修改离开前确认。新建与导入都是独立草稿，不会发布或替换已有故事。指定版本试玩创建新会话，旧会话仍固定原版本。普通新开局仍使用最新版本。

检查发现并修复了多故事侧栏溢出：固定高度且不能滚动时，新建按钮会落到可点击区域外。现在侧栏独立滚动，E2E 在积累十余故事的测试库中完成新建与选择。

- `npm run check` 通过：类型检查、25 项服务端测试、43 项前端测试与生产构建。
- 服务端配置范围行覆盖 99.50%、分支 92.70%；前端配置范围行 100%、分支 86.26%，不是全仓覆盖率。
- 真实 MongoDB 集成 2 项通过，本地使用独立 27018 实例；不清理开发库。
- 4 项 Chromium E2E 通过。新增流程用真实完整稿导入并发布，提交三轮选择后刷新恢复，发布实际不同的 v2，再分别验证 v1/v2 内容；移除浏览器 `randomUUID` 验证 HTTP 回退。既有 MCP 测试只作为兼容回归运行。
- 《二哈有福》新增 6 项引擎回归：编译、四条代表路线、三周目回响/状态重置/真结局。非穷举分支，不声称完整内容覆盖。
- 已查看 1280px 桌面、390px 窄屏截图；导入控件、发布操作和版本按钮可见，页面无横向溢出。截图随 E2E 生成于 `test-results/`。
- 独立代理审查确认导入错误保护、版本选择和剧情状态边界，无阻塞发现。[PR #20 远端 CI](https://github.com/lzfee0227/wawawa/actions/runs/40161150984) 已通过 Ubuntu、MongoDB 7 与完整浏览器验收；后续文档修订同样等待检查后合并。

测试中的导入只发生在 E2E 数据库，不代表用户开发库已导入或发布完整《二哈有福》。导入不推断音色，也不自动解析角色表；作者可配置角色，未配置时回合显示原始 speaker ID。
