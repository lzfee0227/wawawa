# SDD-008: 人物设定与剧情结构可视化

状态：实施规格；2026-10-25。

## 目标

让作者在本地工作室查看人物设定、人物关系和 Ink 剧情结构，帮助检查内容与分支。图表是编辑和调试视图，不取代 Ink 作为剧情权威。

## 验收要求

| ID | 要求 | 验收依据 |
|---|---|---|
| V01 | 角色可保存人物设定 | 草稿刷新后保留简介、性格、目标和秘密 |
| V02 | 角色关系可保存 | 可新增、编辑、删除关系；关系两端必须引用现有角色；关系 ID 在同一草稿内必须唯一 |
| V03 | 可查看人物关系图 | 图形视图与无障碍文本列表展示相同关系 |
| V04 | 可分析剧情结构 | 已保存草稿可生成场景、选项、结局和跳转节点 |
| V05 | 图分析不改变剧情 | 分析接口不执行或修改 Ink 状态，不影响编译、发布和游玩 |
| V06 | 发布版本图可复现 | 发布时保存图快照，后续草稿修改不改变旧版本图 |
| V07 | 图分析失败可解释 | 无法识别或编译失败时返回诊断，不猜测节点和边 |
| V08 | 内容包可重复导入设定 | 《二哈有福》完整稿、8 个说话角色与关系一起校验和导入；保留既有 voiceId；再次保存不丢关系；不改写旧版本及会话 |
| V09 | React Flow 只读画布 | 人物和剧情使用自动布局的节点连线；支持平移、缩放、适配画布、缩略图；禁止增删节点、拖动节点改布局及连线编辑 |
| V10 | 可定位与读取 | 搜索节点并聚焦、点击显示人物/剧情详情；长篇可选择场景查看相邻节点；提供等价文本列表；桌面及 390px 页面无横向溢出 |
| V11 | 图数据状态明确 | 进入剧情视图自动分析当前草稿；切换故事/源码后不显示旧结果；编译和网络错误可见并能重试；只读交互不保存草稿或推进会话 |

V09–V11 测试：浏览器查看真实人物及剧情边、搜索和局部场景、缩放与适配、键盘选择与窄屏；组件测试分析失败重试与源码变化、无写入；图提取回归检查选择归属、长段跳转、定义行号。静态源码图展示已识别结构，不宣称完整可达性或动态目标已解析；旧发布快照不重写。

V08 验收：校验 speaker/关系端点/绑定变量存在；导入前备份草稿；按 revision 更新后读回比较；新版本保存人物与关系、图快照；相同内容重复执行不新增版本。组件回归覆盖已导入关系在编辑正文后仍随保存请求发送。

## 范围

人物关系来自作者配置，剧情图来自 Ink 静态分析。采用 React Flow 与 Dagre 自动布局，画布只读，保留现有资料编辑入口。实际游玩路径高亮、图形编辑和自动回写 Ink 不在本轮范围。
